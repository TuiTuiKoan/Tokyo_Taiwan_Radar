# Tokyo Taiwan Radar 東京台灣雷達

> 🌐 **網站**：[tokyotaiwanradar.com](https://tokyotaiwanradar.com)
> 📅 日本全國台灣相關活動聚合平台（電影、展覽、講座、美食）
> 🇹🇼🇯🇵 三語言（中／日／英）

- 5/11 -
在黃金週的第三週我們達成了很多驚人的目標，開始開通SNS，包含line的QRcode週報訂閱，x, instagram, thread, Facebook.
我們也開始針對日本的PMF做多輪研究，也針對整個站台的監控與觀測性設定更多管理維度的dashboard，覆蓋開發、商業策略、SEO-AEO、資料治理、來源管理等。
我們也針對資料來源的整理與分析做了很多深化，從二手活動介紹頁面進一步拓展到一手資料，涵蓋更多主辦資訊與活動詳情分析。並強化電影與人名的翻譯對照，盡可能參照比對官方與正式名稱。
值得驚喜的是，早稻田大學台日稻門會和灣生日本人集結組成的「東京台湾の会」也主動聯繫合作，有了一個好的開始。

- 5/5 -
進入第二週，我們的資料庫已經爆衝到 633 個活動、163 個來源！不只掃蕩東京，現在全日本的日台交流、獎助金資訊，我們通通都要抓進來！
看著 Google、Claude 和 ChatGPT 的爬蟲整天在「東京台灣雷達」逛大街，那種感覺是什麼？就像我辦了一場電音派對，看著這群 AI 大咖通通在我的場子喝爆、跳爆，只有一個字：爽！
🔥 這裡沒有輕鬆的事，只有硬核的堅持！
三國語言翻譯搏鬥到流鼻血，即便有 AI 跪著幫忙，資料清洗的工作量還是超乎想像。從電影譯名、人名到專業學術發表，管他前方有多少「大魔王」，我通通一個一個打爆給你看！
Line基本串接上線，週報測試發佈一次。並且開始思考商業化的MVP模式，進行市場測試。

- 4/26 -
從4/19開始，一個禮拜，87個來源，41個爬蟲，237筆活動紀錄，「東京台灣雷達」第一版終於比較安定運作了。
一切都起於自己希望能夠在海外幫上忙。喜歡台灣的人，希望讓下一代繼續親近台灣的人，或者自己不夠熟悉，但是希望能夠讓身旁朋友有機會認識台灣的人，都有機會有一個小小的聚集地，可以帶著好奇心，或者，作為生活中一個選項，帶著身旁的日本朋友，美國朋友，菲律賓朋友，甚至中國朋友一起去看看。
這個雷達還很微弱，但他帶著很多大家的愛。希望你也覺得他有點用處。也歡迎你一起來許願，讓他把台灣的訊號，傳到更遠的地方。
