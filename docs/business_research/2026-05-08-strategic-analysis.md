## 1. SWOT 分析

### Strengths（優勢）

| | 說明 |
|---|---|
| S1 | **三語自動化管線** — 30+ 來源、AI 標註、每日自動更新。複製成本對競爭者極高 |
| S2 | **全日本覆蓋** — 不只東京，已包含 47 都道府縣中過半 |
| S3 | **Schema.org / SEO 結構化** — `Event`、`FAQPage`、`BreadcrumbList` 完整 → Google 排名先天優勢 |
| S4 | **公共利益定位清晰** — 入選理由透明、可檢舉、不收推廣費，建立信任護城河 |
| S5 | **17 種分類精細度** — 比 Peatix / Connpass 等通用平台更貼近文化主題 |

### Weaknesses（劣勢）

| | 說明 |
|---|---|
| W1 | **品牌名稱誤導** — 「Tokyo」字眼限制非首都圈用戶搜尋 |
| W2 | **單人運營瓶頸** — 內容審核 / 客服 / BD 不能並行 |
| W3 | **零分發** — 沒有電子報、沒有 SNS、沒有 push 通知，依賴 Google SEO 被動流量 |
| W4 | **無 B2C 留存機制弱** — 雖有 Save 功能但無後續觸發 |
| W5 | **無變現** — 完全依賴個人補貼，財務不可持續 |

### Opportunities（機會）

| | 說明 |
|---|---|
| O1 | **日台關係 2026 大幅升溫** — 半導體、防衛合作、漢字文化圈、米中對立 → 台灣相關內容需求結構性上升 |
| O2 | **インバウンド回復** — 訪日台灣人創歷史新高（2024 年破 600 萬），日本人對台灣興趣同步升高 |
| O3 | **Z 世代 + 在日華人 雙引擎** — 在日台灣人約 6 萬人 + 在日中國人 80 萬人，多數雙語、有付費意願 |
| O4 | **B2B 空白** — 日本沒有任何專業聚合台灣商展 / 文化展演的 B2B 工具，TECRO、台灣文化センター需要這個 |
| O5 | **AI / 自動化紅利** — 個人能用低成本維持生產力（你已驗證） |

### Threats（威脅）

| | 說明 |
|---|---|
| T1 | **大平台收購邏輯** — Peatix、Connpass、Compass 若加台灣標籤，你的差異化縮小 |
| T2 | **資料來源網站封鎖** — 防爬蟲、隱私規範可能切斷管線 |
| T3 | **政治敏感性** — 兩岸議題若觸發某些日本國內反應，可能影響贊助/合作 |
| T4 | **個人健康/興趣風險** — 單點故障 |

### 4 大利害關係人群與需求

| 群體 | 規模 | 痛點 | 願意付的對價 |
|------|------|------|------|
| **A. 在日台灣/華人個人** | ~85 萬 | 想找同鄉社群、家鄉文化 | ¥500–1000/月（小額訂閱、社群活動費） |
| **B. 日本一般消費者（台灣愛好者）** | ~300 萬潛在 | 不知道哪裡有台灣活動 | ¥0（廣告/電子報變現） |

## 8. 是否需要培養日本社交流量？— 戰略結論

### ❗ 直接回答：**SNS 是必要但不是首要**

| 比較項目 | SNS 經營 | B2B 直銷 |
|---|---|---|
| 收入轉換速度 | 慢（6–12 個月） | 快（1–3 個月） |
| 個人時間投入 | 高（每日） | 集中（提案週） |
| ROI（金額/小時） | 低 | **高** |
| 副作用 | 品牌建立、流量 | 不擴大用戶基底 |

**建議分配**：B2B 70% / SNS 20% / SEO 10%

但 SNS **絕不能完全放棄**，因為：

- 它是 B2B 提案的「信任貨幣」（沒有粉絲很難說服客戶）
- 媒體記者用 X 找選題

### Q2: 半自動化增長互動的可能作法

| 方法 | 工具 | 風險 |
|------|------|------|
| **DB → Tweet** 自動發文 | GitHub Actions cron + Twitter API | 低；Twitter API v2 免費額度 1500 tweets/月 |
| **Cross-post**（X → Threads → Bluesky） | Buffer / Hootsuite / Typefully | 低；¥0–¥3,000/月 |
| **AI 寫文案模板** | OpenAI + 你已有的 annotator 邏輯 | 低 |
| Reply bots / 自動 follow | — | **高風險**，禁用 |
| **Engagement pods**（互讚群組） | — | **算法懲罰風險**，避免 |
| **Reposting trending hashtags** | TweetDeck / 手動 | 中 |
| **電子報 → SNS 雙向漏斗** | Buttondown + Zapier | 低，**強烈推薦** |

**演算法核心 (X / Instagram 2026)**：

1. **前 30 分鐘互動率**決定散播 → **發文時間最重要**（X 日本黃金時段 7–9am, 12–13, 21–23）
2. **留言 > 轉推 > 讚**，鼓勵留言（提問形式）
3. **垂直深耕主題** → 演算法會貼「Taiwan in Japan」標籤給你
4. **連結會降權** → 把連結放在第一則回覆，主貼純文字 + 圖
